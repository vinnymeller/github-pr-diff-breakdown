PR Diff Breakdown

These rules are yours alone and apply on top of whatever a repository already defines. They win over a repo's .github/pr-diff-breakdown.yml, which in turn wins over .gitattributes and plain file extensions.

Your overrides

    Example 
    version: 1

# Shorten long counts: "generated +1.3k -2.3k". Use "full" for exact numbers.
numbers: abbreviated

buckets:
  # Rules are tried top to bottom; the first pattern that matches a file wins.
  - label: cassettes
    icon: yaml
    patterns:
      - tests/cassettes/**
      - "**/*.cassette.yaml"

  - label: ci
    color: gray
    patterns: [".github/workflows/**"]

  # Optional: limit a rule to one org or one repo. Omit it and the rule applies
  # everywhere. "camoag" is the whole org; "camoag/api" is that repo alone.
  - label: fixtures
    scope: camoag/api
    patterns: ["tests/fixtures/**"]

  # Reuse the built-in "generated" label to fold files into that bucket — they
  # inherit its striped swatch and sort to the end with everything else you are
  # not being asked to read.
  - label: generated
    patterns: ["**/__snapshots__/**", "*.lock"]

  # A null label means "no match, keep falling through" — use it to undo a
  # rule a repository set, without restating what it should be instead.
  - label: ~
    patterns: ["vendor/**"]

    Patterns are gitignore-style globs. Colors: blue, purple, green, yellow, red, teal, orange, gray, pink, or a hex value like #4493f8.

    Icons are a bundled name or a data: URI. Remote https:// URLs are rejected: GitHub's Content-Security-Policy limits images to its own hosts, so they could never render. Well-known extensions (.py, .md, .rs…) already pick their own.

    Bundled names: c, cplusplus, css, docker, dotnet, elixir, git, gnubash, go, graphql, haskell, html5, javascript, json, julia, kotlin, lua, markdown, nixos, ocaml, perl, php, python, r, react, ruby, rust, sass, scala, svg, swift, terraform, toml, typescript, yaml, zig
